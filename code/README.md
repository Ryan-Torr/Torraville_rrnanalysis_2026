# Purpose

## Data retrieval code/applications
  - Mothur version 1.48.6 is installed in the hidden .pixi environment folder using the following commands in the "/code/" directory using the following commands: 
  1. "pixi workpsace channel add bioconda" to add bioconda package repository
  2. "pixi add mothur" to add the latest version of mothur (1.48.6)
